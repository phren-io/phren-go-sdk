# OperationProgress

How far an export or import has got, in memories (RFC 008). A memory the
target already holds is skipped, not an error. An export's `total` is the
memories it holds. An import is done when its memories are searchable:
`indexed` reaches the imported memories that recall can index.


## Fields

| Field                                                                                                                                 | Type                                                                                                                                  | Required                                                                                                                              | Description                                                                                                                           |
| ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `Total`                                                                                                                               | `int`                                                                                                                                 | :heavy_check_mark:                                                                                                                    | Memories to import, or memories exported.                                                                                             |
| `Imported`                                                                                                                            | `int`                                                                                                                                 | :heavy_check_mark:                                                                                                                    | Memories written so far.                                                                                                              |
| `Skipped`                                                                                                                             | `int`                                                                                                                                 | :heavy_check_mark:                                                                                                                    | Memories skipped because the target already holds them.                                                                               |
| `Indexed`                                                                                                                             | `int`                                                                                                                                 | :heavy_check_mark:                                                                                                                    | Imported memories recall has indexed, so a search finds them. Memories<br/>with nothing but whitespace are never indexed and don't count. |
